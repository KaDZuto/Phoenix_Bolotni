# Модуль биоиндикации и контекстных данных

Данный модуль является **полностью независимым вспомогательным аналитическим пакетом** и никак не затрагивает архитектуру и обучение аудио-классификатора `Phoenix_Bolotni`.

## Принципиальные ограничения
1. **Нейросеть НЕ прогнозирует погоду и НЕ измеряет заболоченность.**
   Классификатор решает ровно одну задачу: определение вида птицы по акустическому сигналу.
2. **Веса приуроченности видов к биотопам заполняются экспертом.**
   В файле `species_weights.json` значения `wetland_affinity` намеренно проинициализированы как `null`. Агент и разработчики намеренно не заполняют эти веса эвристиками: для корректного природоохранного мониторинга коэффициенты должны быть определены профессиональным орнитологом или геоботаником.
3. **Метеоданные — это внешний физический контекст.**
   Файл `weather_client.py` запрашивает фактическую погоду через бесплатный сервис Open-Meteo по координатам и дате записи, чтобы эколог видел температуру и осадки на момент проведения аудиомониторинга.

## Использование
```python
from bioindicator.scorer import WetlandBioindicatorScorer
from bioindicator.weather_client import fetch_weather_context

# 1. Анализ обнаружений
scorer = WetlandBioindicatorScorer()
report = scorer.calculate_score([
    {"species": "anas_platyrhynchos", "timestamp": "2026-05-15T06:00:00Z"},
    {"species": "botaurus_stellaris", "timestamp": "2026-05-15T06:30:00Z"},
])
print(report)

# 2. Получение метеоконтекста
weather = fetch_weather_context(latitude=55.75, longitude=37.61, date_str="2026-05-15")
print(weather["summary"])
```
