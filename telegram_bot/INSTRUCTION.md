## 🌟 Архитектура и ключевые особенности

- **Long Polling:** Бот использует только исходящие HTTPS-запросы к Telegram API. Ему **не требуется белый/публичный IP** и проброс портов.
- **Хранение в Telegram:** Аудиофайлы не занимают постоянное дисковое пространство сервера. Каждый обработанный файл (.wav 32 кГц, моно) пересылается в приватный Telegram-канал-архив, а на сервере сохраняется только SQLite-база (`collector.db`) с метаданными.
- **Автоматическая выгрузка в ZIP:** Каждые 10 новых записей автоматически упаковываются в ZIP-архив (`dataset/<вид>/*.wav` + `manifest.json`) и отправляются прямо в чат администратора.
- **Гарантированное удаление временных файлов:** Все промежуточные файлы очищаются сразу после конвертации и отправки.
- **Telegram Mini App (WaveSurfer.js):** Встроенный веб-плеер позволяет пальцем выделить точный промежуток песни на спектрограмме.
- **Безопасный аудио-прокси:** Для прослушивания аудио в браузере реализован защищенный прокси с одноразовыми подписями HMAC-SHA256, скрывающий токен бота.

## 🛠 Подготовка Telegram

### 1. Создание бота через [@BotFather](https://t.me/BotFather)
1. Откройте диалог с [@BotFather](https://t.me/BotFather).
2. Отправьте `/newbot`, укажите имя и юзернейм (например, `phoenix_birds_collector_bot`).
3. Скопируйте полученный **HTTP API Token** (сохраните в `BOT_TOKEN`).

### 2. Создание приватного канала-архива
1. Создайте в Telegram **приватный канал** (например, `Phoenix Audio Archive`).
2. Добавьте созданного бота в администраторы этого канала с правами отправки сообщений.
3. Узнайте ID канала (начинается с `-100...`). Для этого перешлите любое сообщение из канала боту `@username_to_id_bot` или `@JsonDumpBot`. Сохраните ID в `ARCHIVE_CHANNEL_ID`.

### 3. Определение ID администратора
Узнайте свой личный Telegram ID (через `@userinfobot`). Сохраните его в `ADMIN_CHAT_ID` и `ADMIN_USER_IDS`.

### 4. Настройка Mini App (Web App) кнопки в BotFather
1. В [@BotFather](https://t.me/BotFather) введите `/mybots` → выберите вашего бота.
2. Перейдите: **Bot Settings** → **Menu Button** → **Configure menu button**.
3. Введите URL Mini App: `https://<ваш_домен_или_ip>:8080/webapp` и текст кнопки, например: `🎧 Разметка`.

## ⚙️ Настройка окружения

В папке `telegram_bot/` создайте файл `.env`:

```ini
# Токен бота от @BotFather
BOT_TOKEN=123456789:ABCdefGHIjklMNOpqrSTUvwxYZ

# ID приватного канала-архива (начинается с -100)
ARCHIVE_CHANNEL_ID=-1001234567890

# ID чата администратора для получения батч-архивов .zip
ADMIN_CHAT_ID=12345678

# Список ID администраторов через запятую
ADMIN_USER_IDS=12345678

# Размер пакета для автоматической сборки архива (по умолчанию 10)
BATCH_SIZE=10

# Базовый URL Mini App и аудио-прокси
WEBAPP_URL=http://localhost:8080/webapp
PROXY_HOST=0.0.0.0
PROXY_PORT=8080
PROXY_URL_BASE=http://localhost:8080/api/audio

# Секретный ключ для подписи ссылок прослушивания (смените на свой!)
PROXY_SECRET=phoenix_bolotni_super_secret_key_change_me
```

## 🚀 Варианты запуска

### Вариант А: Запуск в Python Virtualenv

1. Перейдите в каталог `telegram_bot`:
   ```bash
   cd /root/Phoenix_Bolotni/telegram_bot
   ```
2. Убедитесь, что установлен `ffmpeg`:
   ```bash
   sudo apt-get update && sudo apt-get install -y ffmpeg
   ```
3. Создайте виртуальное окружение и установите зависимости:
   ```bash
   python3 -m venv venv
   source venv/bin/activate
   pip install -r requirements.txt
   ```
4. Запустите тесты для проверки работоспособности:
   ```bash
   pytest tests/ -v
   ```
5. Запустите бота и аудио-прокси:
   ```bash
   python -m collector_bot.main
   ```

---

### Вариант Б: Запуск в Docker / Docker Compose

1. Перейдите в папку бота:
   ```bash
   cd /root/Phoenix_Bolotni/telegram_bot
   ```
2. Поднимите контейнер:
   ```bash
   docker-compose up -d --build
   ```
3. Проверьте статус и логи:
   ```bash
   docker-compose logs -f
   ```

---

### Вариант В: Запуск через Systemd

Создайте файл `/etc/systemd/system/phoenix-bot.service`:
```ini
[Unit]
Description=Phoenix_Bolotni Telegram Data Collector Bot
After=network.target

[Service]
Type=simple
User=root
WorkingDirectory=/root/Phoenix_Bolotni/telegram_bot
EnvironmentFile=/root/Phoenix_Bolotni/telegram_bot/.env
ExecStart=/root/Phoenix_Bolotni/telegram_bot/venv/bin/python -m collector_bot.main
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```

Активируйте службу:
```bash
systemctl daemon-reload
systemctl enable --now phoenix-bot
systemctl status phoenix-bot
```

## 📱 Руководство пользователя (эколога)

1. **Команда `/start`:**
   - При первом запуске бот просит подтвердить согласие на использование записей в открытом научном датасете.
   - Нажмите кнопку `✅ Согласен(-на) с условиями`.
2. **Отправка записи:**
   - Запишите голосовое сообщение прямо в Telegram или прикрепите аудиофайл (`.ogg`, `.mp3`, `.wav`, `.m4a`).
3. **Выбор способа разметки:**
   - **⚡ Быстрая разметка (весь клип):** для коротких чистых записей одного вида. Бот откроет клавиатуру видов птиц фауны РФ с фильтрами по биотопам (`болотные`, `лесные`, `городские`, `степные`).
   - **🎧 Точная разметка (открыть плеер):** открывает Mini App. Вы можете пальцем выделить нужный отрезок на спектрограмме, зациклить его кнопкой `🔁` для проверки и нажать `✅ Сохранить фрагмент`.
4. **Кнопка «➕ Другой вид (нет в списке)»:**
   - Если птица отсутствует в справочнике, нажмите кнопку и напишите её название текстом (по-русски или латынью). Запись будет сохранена и передана на проверку эксперту.
5. **Геолокация и комментарий:**
   - После разметки бот предложит отправить геопозицию и текстовый комментарий к биотопу (по желанию).
6. **Отмена записи:**
   - Если вы ошиблись при выборе вида, отправьте `/undo` — последняя запись будет удалена.

## 👑 Руководство администратора и эксперта

### Основные команды
- `/stats` — показывает количество собранных записей по каждому виду (сортировка по возрастанию — сразу видно, каких видов не хватает), статус текущего батча и личный рейтинг.
- `/export` — принудительно выгрузить текущие размеченные записи в ZIP-архив сейчас, не дожидаясь порога в 10 записей.
- `/new_species_requests` — список видов, предложенных пользователями через «Другой вид», с количеством клипов.
- `/reload_whitelist` — перечитывает `species/ru_birds_whitelist.json` на лету без перезапуска сервиса.
- `/review <submission_id> approve|reject` — подтверждает или отклоняет правильность разметки контрибьютора.
- `/trust [user_id]` — проверка метрики доверия контрибьютора.
- `/top_contributors` — список лидеров проекта по числу принятых записей.

### Структура выгружаемого ZIP-архива
```
batch_20261005_120000_abc123.zip
├── dataset/
│   ├── anas_platyrhynchos/
│   │   ├── 4b8d7c22-....wav
│   │   └── 9c1f2e33-....wav
│   ├── ardea_cinerea/
│   │   └── 3a2b1c00-....wav
│   └── _proposed_species/
│       └── Болотная_сова_Asio_flammeus/
│           └── d4e5f600-....wav
└── manifest.json
```

Все аудиофайлы в архиве уже приведены к формату `32000 Гц, моно, 16-bit PCM WAV` и готовы для подачи в пайплайн обучения модели (`prepare_data.py`).

### Синхронизация списка видов из модели
Для обновления whitelist и настроек модели из корня репозитория:
```bash
python scripts/sync_from_model_repo.py --model-repo ..
```
После чего выполните команду `/reload_whitelist` в чате с ботом.

### Мониторинг диска
Для проверки отсутствия зависших файлов в папке `tmp/`:
```bash
./scripts/check_tmp_clean.sh
```

## 🔍 Решение проблем

1. **Бот не отвечает на сообщения:**
   - Проверьте корректность `BOT_TOKEN` в `.env`.
   - Проверьте доступ в интернет с сервера (`curl -sI https://api.telegram.org`).
2. **Ошибка при архивации (не уходит в канал):**
   - Убедитесь, что бот добавлен в администраторы архивного канала с правом публикации сообщений.
   - Проверьте `ARCHIVE_CHANNEL_ID` (он должен быть отрицательным числом, начинающимся с `-100`).
3. **Плеер Mini App не проигрывает аудио:**
   - Проверьте `WEBAPP_URL` и доступность порта `8080`.
   - Убедитесь, что значение `PROXY_SECRET` совпадает в конфигурации.
