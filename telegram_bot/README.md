# Phoenix_Bolotni Collector Bot 🐦

Telegram-бот сбора и предварительной разметки аудиозаписей птиц фауны Российской Федерации.
Разработан как независимый сервис для экологов и полевых исследователей.

---

## 📌 Архитектура и принципы работы

1. **Режим Long Polling (исходящие соединения):**
   - Бот инициирует исходящие HTTPS-запросы к `api.telegram.org`.
   - **Белый / публичный IP-адрес для самого бота не требуется!** Бот стабильно работает за NAT, VPN или мобильным интернетом.
2. **Нулевой след на диске (Telegram as storage):**
   - Бот не хранит аудиофайлы на диске сервера.
   - Все размеченные файлы сразу конвертируются в 32 кГц моно WAV и пересылаются в приватный Telegram-канал-архив.
   - Временные файлы удаляются немедленно после отправки (в блоках `try...finally`).
   - На сервере хранится только компактная база данных SQLite (`collector.db`) с метаданными.
3. **Строгая привязка к фауне РФ:**
   - Список видов берется строго из синхронизированного `species/ru_birds_whitelist.json`.
   - Любой отсутствующий вид оформляется через кнопку **«➕ Другой вид (нет в списке)»** и отправляется на ручную верификацию экспертом без добавления непроверенных названий в модель.

## 🚀 Быстрый старт

### 1. Установка зависимостей
```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```
Требуется установленный `ffmpeg` в системе:
```bash
sudo apt update && sudo apt install -y ffmpeg
```

### 2. Конфигурация переменных окружения
Создайте файл `.env` или передайте переменные окружения:
```ini
BOT_TOKEN=123456789:ABCdefGHIjklMNOpqrSTUvwxYZ
ARCHIVE_CHANNEL_ID=-1001234567890
ADMIN_CHAT_ID=12345678
ADMIN_USER_IDS=12345678,87654321
BATCH_SIZE=10
WEBAPP_URL=https://your-domain.example/webapp
PROXY_SECRET=your_super_secret_hmac_key
```

### 3. Запуск бота
```bash
python -m collector_bot.main
```

## 🛠 Развертывание в продакшене

### Systemd Unit (`/etc/systemd/system/phoenix-collector.service`)
```ini
[Unit]
Description=Phoenix_Bolotni Telegram Collector Bot
After=network.target

[Service]
Type=simple
User=root
WorkingDirectory=/root/Phoenix_Bolotni_Collector
EnvironmentFile=/root/Phoenix_Bolotni_Collector/.env
ExecStart=/root/Phoenix_Bolotni_Collector/venv/bin/python -m collector_bot.main
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```
Активация:
```bash
systemctl daemon-reload
systemctl enable --now phoenix-collector
```

### Docker Compose (`docker-compose.yml`)
```yaml
version: '3.8'

services:
  collector:
    build: .
    restart: always
    env_file: .env
    volumes:
      - ./collector.db:/app/collector.db
      - ./tmp:/app/tmp
    ports:
      - "8080:8080"
```

## 📱 Команды бота

- `/start` — регистрация согласия на использование данных и инструкция.
- `/stats` — статистика собранных клипов по видам (в порядке возрастания количества) и личный рейтинг контрибьютора.
- `/undo` — отмена последней присланной записи (до отправки в проверочный пакет).
- `/trust [id]` — подробная метрика доверия и статистика подтвержденных записей.
- `/top_contributors` — рейтинг лучших контрибьюторов проекта.
- `/export` — *(Админ)* принудительный экспорт пакета записей в ZIP.
- `/new_species_requests` — *(Админ)* список предложенных пользователями видов.
- `/reload_whitelist` — *(Админ)* перечитывание `ru_birds_whitelist.json` без рестарта сервиса.
- `/review <id> approve|reject` — *(Админ)* подтверждение корректности вида и начисление рейтинга доверия контрибьютору.

## 🎧 Telegram Mini App (Веб-плеер точной разметки)

Для записей с шумом или сложным звуковым окружением предусмотрен встроенный плеер на базе **WaveSurfer.js + Regions Plugin**:
- Интерактивная спектрограмма аудиозаписи с возможностью пальцем растягивать и перемещать границы выделения;
- Кнопка 🔁 **«Зациклить фрагмент»** для многократного прослушивания выделенного промежутка перед подтверждением;
- Замедление воспроизведения (0.5× / 0.75× / 1.0×) для четкого различения быстрых птичьих трелей;
- Поиск по видам фауны РФ и фильтрация по биотопам (`wetland`, `forest`, `urban`, `field_steppe`);
- Кнопка **«➕ Другой вид»** для ручного ввода неучтенных видов птиц;
- Адаптация под системную тему оформления (светлая/тёмная) через `Telegram.WebApp.themeParams`.

### Настройка в BotFather
1. Откройте [@BotFather](https://t.me/BotFather) в Telegram.
2. Выберите `/mybots` → выберите вашего бота.
3. Перейдите в **Bot Settings** → **Menu Button** → **Configure menu button**.
4. Укажите URL Mini App: `https://your-domain.example/webapp` и текст кнопки, например: `🎧 Разметка`.

### Архитектурный компромисс: тонкий защищенный аудио-прокси
> [!IMPORTANT]
> **Почему необходим прокси и почему нельзя отдавать прямую ссылку Telegram Bot API:**
> Прямая ссылка на файл вида `https://api.telegram.org/file/bot<BOT_TOKEN>/...` содержит секретный токен бота. Если передать такую ссылку в веб-браузер, токен станет доступен пользователю (через DevTools или сетевой лог), что позволит любому стороннему лицу отправлять команды от имени бота.
> 
> **Решение:**
> Единственный публичный эндпоинт во всем проекте — `GET /api/audio/{submission_id}?sig=...`.
> Доступ защищен одноразовой подписью HMAC-SHA256 со сроком жизни 15 минут. Прокси самостоятельно запрашивает файл у Telegram Bot API и стримит байты в браузер клиента, сохраняя токен в полной тайне.
> 
> **Сохранение без публичных POST-эндпоинтов:**
> Результат разметки передается через нативный метод `Telegram.WebApp.sendData(json)`. Данные приходят боту внутри того же long polling соединения, исключая необходимость в открытии внешних портов для записи.

## 🏆 Метрика доверия контрибьютора (Trust Metric)

Для поощрения добросовестных исследователей и отсева спама реализована система репутации контрибьюторов:
1. За каждую отправленную запись в профиле пользователя в SQLite фиксируется факт участия.
2. После проверки пакета экспертом команда `/review <id> approve` увеличивает счетчик принятых записей контрибьютора, а `/review <id> reject` — отклоненных.
3. **Рейтинг доверия:** $\text{Trust Rate} = \frac{\text{Accepted}}{\text{Accepted} + \text{Rejected}} \times 100\%$.
4. Команда `/top_contributors` выводит доску лидеров среди исследователей.
5. Индивидуальный рейтинг отображается в `/stats` и `/trust`.

## 🔄 Синхронизация с репозиторием модели

Слаги видов в клавиатуре и манифесте батч-архива **строго 1:1 совпадают** с репозиторием модели `Phoenix_Bolotni`:
- Файлы `species/ru_birds_whitelist.json` и `model_config.json` не шарят git-историю, а копируются независимым скриптом:
```bash
python scripts/sync_from_model_repo.py --model-repo /root/Phoenix_Bolotni
```
- После обновления whitelist на работающем сервере администратор может выполнить команду `/reload_whitelist` в чате с ботом, и новые виды немедленно станут доступны пользователям без перезапуска контейнера или службы.
