# Phoenix Bolotni — Android App

Официальное Android-приложение для проекта **Phoenix_Bolotni** (Феникс Болотный).

Приложение выполняет непрерывное офлайн-распознавание голосов птиц по звуку прямо на смартфоне в полевых условиях без необходимости подключения к сети Интернет.

---

## Архитектура и выполненные задачи

### 1. Задача 1 [P0] — Базовая интеграция модели (ONNX Runtime Mobile)
- **Модель:** `bird_model.onnx` загружается через `com.microsoft.onnxruntime:onnxruntime-android`.
- **Нативный препроцессинг:** [`AudioPreprocessor.kt`](app/src/main/java/com/phoenix/bolotni/model/AudioPreprocessor.kt) строго следует параметрам из `model_config.json`:
  - Частота дискретизации: 32 000 Гц (ресемплинг при необходимости).
  - STFT: окно Ханна (1024), hop (320), center padding.
  - Мел-фильтры: HTK Mel filterbank (128 мел-фильтров от 0 до 16 000 Гц).
  - Нормализация: логарифмирование и Z-score стандартизация.
  - Формирование 3-канального тензора `[1, 3, 128, 501]`.
- **Контракт:** параметры читаются динамически из `model_config.json` без хардкода.
- Поддерживает полноразмерные и квантованные (int8) ONNX модели.

### 2. Задача 2 [P0] — Непрерывное прослушивание + многократная проверка (без ложной уверенности)
- **Фоновый сервис:** [`ContinuousListeningService.kt`](app/src/main/java/com/phoenix/bolotni/service/ContinuousListeningService.kt) как Foreground Service с постоянным уведомлением.
- **Кольцевой буфер:** [`AudioCaptureManager.kt`](app/src/main/java/com/phoenix/bolotni/service/AudioCaptureManager.kt) производит захват аудио без разрывов и нарезает поток на окна длиной 5.0 с с шагом 2.5 с.
- **Многократная проверка:** [`WindowVoteEngine.kt`](app/src/main/java/com/phoenix/bolotni/model/WindowVoteEngine.kt) подтверждает вид только при совпадении как минимум в 2 из последних 3 окон. Случайные одиночные всплески шума отсекаются и не показываются как результат.
- Поддерживает Test-Time Augmentation (TTA) со сдвигом по времени `[-200, 0, 200] мс`.

### 3. Задача 3 [P1] — Разрешения, фоновая работа и приватность
- Runtime-запросы `RECORD_AUDIO`, `FOREGROUND_SERVICE_MICROPHONE`, `ACCESS_FINE_LOCATION`, `POST_NOTIFICATIONS` с обоснованием.
- Быстрый доступ к паузе и остановке в один тап с главного экрана и из шторки уведомлений.
- Полные многочасовые записи звука **никогда не сохраняются** на диск. Сохраняются только 5-секундные фрагменты подтверждённых детекций для личного прослушивания пользователем с ротацией по объёму кэша (50 МБ).

### 4. Задача 4 [P2] — Опциональная интеграция с сервером и Telegram-ботом разметки
- Два независимых, выключенных по умолчанию тумблера:
  1. **Сеть наблюдений:** накапливает статистику в офлайн-очереди; при наличии интернета отправляет метаданные на `POST /ingest` сервера (без сырого аудио).
  2. **Экспертная разметка:** системный Share-Intent через [`ShareIntentHelper.kt`](app/src/main/java/com/phoenix/bolotni/network/ShareIntentHelper.kt) позволяет поделиться WAV-файлом с Telegram-ботом разметки. Работает и при отсутствии сети в момент нажатия (Android поставит отправку в очередь).

### 5. Задача 5 [P1] — UI/UX на Jetpack Compose
- **Главный экран:** крупный индикатор статуса, кнопка старт/пауза, лента подтверждённых детекций с русскими названиями и биотопами.
- **Детали детекции:** аудиоплеер 5-секундного фрагмента, число подтверждающих окон, ручная корректировка вида, кнопка отправки в Telegram.
- **Дневник наблюдений:** группировка, поиск по видам, фильтр по биотопам (`wetland`, `forest`, `field_steppe`, `urban`).
- **Справочник видов:** список из `ru_birds_whitelist.json` с русскими названиями.
- **Тема:** поддержка светлой и тёмной тем Material 3.

### 6. Задача 6 [P2] — Обновление модели без публикации в Google Play
- [`ModelUpdateManager.kt`](app/src/main/java/com/phoenix/bolotni/model/ModelUpdateManager.kt) проверяет манифест версии.
- Скачивание бандла по HTTPS, сверка контрольной суммы SHA-256.
- Подмена активной модели на лету в `ModelRunner` без перезапуска и переустановки APK.
- Автоматический откат на встроенные ассеты при повреждении загруженного файла.

### 7. Задача 7 [P0] — Локальная база детекций и статистика (полностью офлайн)
- Локальная база данных Room: [`DetectionsDatabase.kt`](app/src/main/java/com/phoenix/bolotni/local/DetectionsDatabase.kt) и [`DetectionDao.kt`](app/src/main/java/com/phoenix/bolotni/local/DetectionDao.kt).
- Поля схемы зеркалируют серверную таблицу `detections` (`species_slug`, `confidence`, `window_start_ts`, `window_end_ts`, `lat`, `lon`, `created_at`).
- Офлайн-аналитика и экспорт данных в CSV и GeoJSON через [`StatsAggregator.kt`](app/src/main/java/com/phoenix/bolotni/local/StatsAggregator.kt) для полевых биологов.
- Нулевая зависимость от сети — ни один шаг распознавания или записи в БД не блокируется на сетевой вызов.
